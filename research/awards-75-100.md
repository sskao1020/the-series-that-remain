# Awards research: series 75–100

Research date: 2026-08-10

## Scope and data rule

- Primary sources only: Television Academy (Emmys), BAFTA, Peabody, Golden Globes and SAG-AFTRA.
- `nominations` means all nominations in the cited organisation's programme record; wins are a subset of nominations. This makes `wins / nominations` computable later.
- A missing organisation total is `null`, not zero. Zero is used only when the official programme record explicitly contains no nomination.
- Representative records below are intentionally a small sample. The cited official programme page is the canonical source for the complete roster.
- `awardYear` is the award body's labelled year. `ceremonyDate` is omitted unless it differs materially from that year.

## Recommended database shape

```ts
type AwardOrganizationSummary = {
  organization: "emmys" | "bafta" | "goldenGlobes" | "sag" | "peabody";
  nominations: number | null;
  wins: number | null;
  sourceUrl: string;
  verifiedAt: string;
};

type AwardRecord = {
  organization: AwardOrganizationSummary["organization"];
  awardYear: number;
  category: string;
  recipient: string;
  result: "won" | "nominated";
  ceremonyDate?: string;
  sourceUrl: string;
};
```

## Important ingestion notes

1. Do not add a win and a nomination as two records for the same result: a winning record already counts in both the nomination denominator and win numerator through `result: "won"`.
2. Television Academy Honors and Peabody Awards are honours, not competitive Emmy nominations; keep them as separate organisation/event records.
3. BAFTA's site does not consistently expose a programme-level nominations/wins header. Compute totals from deduplicated official result records, retaining the edition and production identity.
4. The live Television Academy page is the source of truth where this note says `null` or “import at ingestion time”; do not convert an unavailable total to zero.
